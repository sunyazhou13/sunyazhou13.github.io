🧩 PastePro · macOS 剪贴板管理器

第一个做完并放出安装包的桌面工具。常驻菜单栏，把复制过的东西都记下来；要用了按 ⇧⌘V 唤出底部通栏面板，选一张直接粘回去。交互参考 Paste，付费、账号、订阅那一整套全省掉 —— 免费，数据只留在本机。

方面说明
内容文本 / 富文本 / 链接 / 图片 / 文件 / 颜色，SHA256 去重，历史上限默认 500 条
交互键盘或滚轮「一格一张」翻卡、⌘1–⌘9 快贴、空格 Quick Look、长按 ⌫ / ⌦ 连续删除
整理多图钉板（7 色 / 排序 / 固定）、回收站与删除撤销、搜索、全局热键自定义 + 冲突检测
数据SQLCipher 加密（WCDB.swift ORM），设置走 MMKV，无网络请求、无遥测
环境macOS 14.0+，Apple Silicon / Intel，安装包约 8 MB

⬇ 下载 PastePro-1.0.1.dmg · 发布说明与历史版本

两个小提醒：安装包是 ad-hoc 签名、未做 Apple 公证，首次打开会被 Gatekeeper 拦一下，跑一句 xattr -cr /Applications/PastePro.app 或在「系统设置 → 隐私与安全性」点「仍要打开」即可；「选中即粘贴」还需要授予辅助功能权限。

源码仓库暂时仍是 private，分发仓库只放构建产物和 Release Note。

🖥 Windows / Linux（Electron 跨平台版 · 实验性）

另一套实现：Electron + JSON 存储，目标是让三个平台的界面与交互保持一致，版本 0.1.0。 ⚠️ 它和上面的 macOS 原生版不是同一套代码，暂不含 SQLCipher 加密、WCDB / MMKV 与图钉板，功能还在迭代。

平台下载
Windows x64安装版 exe · 免安装 zip
Linux x86_64AppImage · deb
Linux arm64AppImage · deb

完整说明与 SHA-256 见 Release 页面。Linux 上「选中即粘贴」会自动挑可用的注入方式（xdotool / 内置 XTEST / wtype / ydotool）；纯 Wayland 或工具全缺时，复制后手动粘贴也一样能用。

🎬 AVIFBrewery3 · 视频 / GIF 转 AVIF

第二个做完的桌面工具：把一段视频或 GIF 剪一段、调调色、叠个滤镜和字幕，再导出成 AVIF 动图序列或 GIF。编码全在本地跑（libavif + libaom + FFmpeg 都打进 App），素材不上传；同样免费、无订阅、无账号。

方面说明
导入MP4 / MOV / M4V / AVI / MKV / WebM / GIF，队列里挂多个素材逐个导出
剪辑时间轴拖游标选区间，Clip Focus 只预览当前片段
画面Resize（Lanczos）、Crop（红框 + 8 手柄）、旋转 / 拉直 / 镜像、滤镜栈、文字与图片叠加（含时序）
编码AVIF / GIF；帧率、帧数、质量、色数、色度采样、编码速度都可调
环境macOS 14.0+，仅 Apple Silicon (arm64)，安装包约 16.2 MB

⬇ 下载 AVIFBrewery3-1.0.0-arm64.dmg · 发布说明与免挂载 ZIP

安装包是 ad-hoc 签名、未做 Apple 公证，首次打开会被 Gatekeeper 拦一下：在「系统设置 → 隐私与安全性」点「仍要打开」，或跑一句 xattr -dr com.apple.quarantine /Applications/AVIFBrewery3.app。App 开了沙盒，读写素材走系统授权的文件选择器。

源码仓库暂时仍是 private，分发仓库只放构建产物和 Release Note。当前只有 arm64 版，Intel Mac 可用项目里的 package.sh -u 自行编 Universal 2。
