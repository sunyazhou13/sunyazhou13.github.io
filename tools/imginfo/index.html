图片元数据查看器

拖入一张图片，浏览器本地解析出完整技术参数：格式、尺寸、位深、色彩类型、透明通道、是否动画，以及 EXIF 相机信息与 ICC 色彩配置。支持 PNG / JPEG / GIF / WebP / AVIF / HEIC / TIFF / BMP 等主流与最新格式，分组表格与 JSON 双视图、一键复制。全部在本机完成，文件不会上传。

拖入或点击选择图片文件

支持的格式与怎么读
1. 本工具支持的格式
格式容器 / 编码透明动画元数据
PNG无损位图（zlib/deflate）支持（RGBA）支持（APNG，acTL）内置 iTXt / tEXt / 可嵌 ICC
JPEG有损（DCT），JFIF / EXIF不支持不支持EXIF / ICC / XMP
GIF调色板位图（LZW）1 位（单色透明）支持（多帧）仅基础，无 EXIF
WebPVP8 / VP8L / VP8X支持（无损 / 有损均带 alpha）支持（ANMF）EXIF / ICC / XMP
AVIFAV1 帧（ISOBMFF）支持（auxC alpha）支持（多 trak）EXIF / ICC（meta 盒子）
HEIC / HEIFHEVC 帧（ISOBMFF）支持（auxC alpha）支持（多 trak）EXIF / ICC（meta 盒子）
TIFF标签式位图（IFD）支持（ExtraSamples）不支持原生 IFD / EXIF / ICC
BMP设备无关位图支持（32 位 BGRA）不支持基本无
本工具直接读文件字节：格式靠魔数识别，尺寸靠各格式头部（PNG 的 IHDR、GIF 头、JPEG 的 SOF、BMP 头、TIFF/EXIF 的 IFD、HEIC/AVIF 的 ispe 盒子），因此即使浏览器无法解码像素（如 HEIC），也能读出完整元数据。
2. 怎么读一份图片参数
  1. 格式 + MIME —— 确认是不是目标格式，有没有被错误命名（如 .png 实为 JPEG）
  2. 尺寸（宽 × 高）+ 宽高比 —— 决定分辨率与原图是否裁切过
  3. 位深 + 色彩类型 —— 8 bit 还是 10/12 bit；RGB / YCbCr / 灰度 / 索引色，决定色域与文件体积
  4. 透明通道 —— PNG / WebP / HEIC / AVIF 可能带 alpha，嵌网页或合成前务必确认
  5. 动画 —— GIF / 动态 WebP / 动态 AVIF / APNG 会标出帧数
  6. EXIF —— 相机厂商、型号、拍摄时间、ISO、曝光、光圈、焦距、GPS 等（来自带 EXIF 的 JPEG / PNG / WebP / TIFF / HEIC / HEIF / AVIF）
  7. ICC 色彩配置 —— sRGB / Display P3 / Adobe RGB 等，跨设备显示一致性的关键
 说明 / 合理范围列：EXIF 每个字段右侧会标出该字段的常见取值范围与当前值是否合理（例如 ISO 常见 50–409600、光圈常见 f/1.0–f/32），明显偏离常见范围的值标 ⚠。GPS 一行还会把 WGS-84 坐标通过国内地图接口反查成中文地址（腾讯 / 高德二选一，需在 assets/tools/imginfo/app.js 的 GEO_KEYS 中填入 key；未配置或查询失败时显示 N/A）。注意：反查在浏览器端发起，该坐标会发送给所选地图服务商（其余解析仍全程本地、不上传）。
 三个常见坑： ① 文件名后缀不可信——有些文件扩展名和实际编码不一致，本工具以魔数判定为准； ② HEIC 在多数浏览器里无法直接解码像素，但本工具仍能读出尺寸、色彩与 EXIF； ③ 截图 / 网络图常被重编码为 8 bit sRGB，原始相机的 10 bit / P3 信息会丢失，看参数能立刻发现。
