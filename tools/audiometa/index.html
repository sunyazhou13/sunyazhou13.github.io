音频元数据查看器

拖入一个音频文件，浏览器本地解析出元数据标签（标题、艺术家、专辑、音轨、年份、流派、歌词、ReplayGain 等）与技术参数（编码、采样率、位深、声道、码率、时长、无损与否等），并展示内嵌封面，还能直接在页面里试听。支持 FLAC / ALAC / APE / WAV / AIFF / DXD / MP3 / AAC / M4A / WMA / OGG / OPUS / MP2 / DSF / DFF / AC-3 / DTS 以及 M3U / M3U8 播放列表。全部在本机完成，文件不会上传。

拖入或点击选择音频文件

支持情况与读数说明

2. 怎么读这些数字

  • 采样率 —— 每秒采样点数。44.1 kHz 为 CD，48 kHz 为影视/流媒体，96 kHz 及以上为 Hi-Res；DSD 的数值（如 2.8224 MHz）是 1-bit 比特率，不是 PCM 采样率。
  • 位深 —— 每次采样的量化精度。16 bit 为 CD，24 bit 为录音室/Hi-Res；DSD 固定为 1 bit。
  • 码率 —— 每秒数据量。有损常见 96–320 kbps；无损（FLAC/ALAC/APE/WAV）码率随内容波动，仅作参考。
  • 时长 —— 由样本数 ÷ 采样率推算；VBR 有损文件为逐帧累计估算，可能有毫秒级误差。
  • 标签里的「说明 / 合理性」列 —— 标出该字段的常见范围；明显偏离常见值会标 ⚠，无对应说明的填 N/A。

3. 关于试听

头部区域有一个原生播放器，直接播放本机文件，同样不上传。能否播放取决于浏览器自带的解码器，与本工具能否解析是两回事：

  • 一般可直接播放 —— MP3 / MP2 / AAC / M4A / ALAC / FLAC / WAV / AIFF / OGG / OPUS。
  • 浏览器放不了 —— DSF / DFF（DSD 的 1-bit 码流）、APE、WMA、AC-3、DTS。这些格式的参数与标签照样读得出来，只是没有原生解码器。
  • 可以转码后听 —— 上面这几种拖进来就会自动转码并播放：页面内置的 ffmpeg（WebAssembly 版）把音频转成 44.1 kHz / 16 bit PCM 再交给播放器。首次会载入约 32 MB 的解码核心，之后同一页面内复用；转码同样全在本机完成，不上传。
  • DFF 会先被重新封装成 DSF 再交给 ffmpeg —— 因为 ffmpeg 没有 DSDIFF 解复用器。两者的音频数据有两处差异：DFF 是逐字节交错而 DSF 是每声道 4096 字节分块；DFF 是 MSB 优先而 DSF 是 LSB 优先，逐字节做位反转。少做一步解出来就是噪声。
  • 播放器下方会给出浏览器解码时长与解析时长的比对：两者一致，说明解析器算出的时长没问题；个别 MP3 缺少 Xing / VBRI 头时会有偏差。

4. 数据来源与隐私

所有解析与播放均在浏览器本地完成，文件不上传、不留存。
