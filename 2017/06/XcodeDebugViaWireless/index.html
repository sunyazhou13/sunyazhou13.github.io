效果

今天小伙伴(王可成)发现Xcode有个很方便的功能 可以真机无线调试运行

看一张图

配置

第一步 选择设备选项

第二步 点勾选 via network

剩下的工作就是拔掉那个我们非常讨厌而且有不得不用还死贵且总折头处的白色数据线了

注意:第一次运行的时候比较慢 可以通过数据线插上先运行一次 运行环境: Xcode9 beta 运行设备操作系统: iOS11 beta Macbook+iPhone 最好在同一个局域网
